# UPSC Prelims — Current Affairs Notes

A structured repository of current-affairs notes for the UPSC Civil Services
Preliminary Examination, organised in the section-wise style of monthly
current-affairs magazines.

## Latest Edition

| Edition | File |
|---------|------|
| July 2026 | [CURRENT_AFFAIRS_JULY_2026.md](CURRENT_AFFAIRS_JULY_2026.md) |

`CURRENT_AFFAIRS_JULY_2026.md` is the consolidated, single-file edition for the
month of July 2026. It follows the standard monthly-magazine format:

- Numbered sections, each opening with long-form **"Why in News?"** items.
- Background explainers, comparison tables, **Challenges / Way Forward / Conclusion**.
- A **News in Shorts** subsection of concise, factual items.

Each section folder holds the corresponding portion of the July 2026 edition in
its `notes.md`, while the combined file at the repository root contains the full
edition in reading order.

## How to use

- Read the combined file top-to-bottom for a full month's revision.
- Or open an individual section folder to revise one topic at a time.
- Add new monthly editions as separate files at the root (e.g.
  `CURRENT_AFFAIRS_AUGUST_2026.md`).
